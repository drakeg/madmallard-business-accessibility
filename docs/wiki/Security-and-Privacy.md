# Security and Privacy

- Only audit sites you operate or are expressly authorized to test.
- No anonymous arbitrary-target scanning. Account permissions, CSRF protections, and URL/network checks protect access but do not replace network egress isolation.
- Never share database credentials, API tokens, setup secrets, client-site credentials, private reports, or personal information in Issues or Discussions.
- Use HTTPS for public deployments. Limit local HTTP testing to trusted LAN networks.
- For security concerns, contact the maintainer privately via GitHub private vulnerability reporting where enabled; do not disclose exploitable details publicly.

See [SECURITY.md](https://github.com/drakeg/madmallard-business-accessibility/blob/main/SECURITY.md) for current security guidance. This project has no published open-source license yet; becoming public does not by itself permit redistribution or derivative software.
