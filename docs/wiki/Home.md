# Mad Mallard Accessibility Workbench

Welcome to the project knowledge base. This documentation is prepared for GitHub Wiki publication **if the repository becomes public**; it is version-controlled in the main repository until then.

The Workbench helps small web agencies and SMB operators audit **authorized** websites, prioritize accessibility and on-page SEO findings, keep review notes, and generate repeatable evidence reports. Automated checks are not a claim of WCAG conformity, legal compliance, or search rankings.
